# Aayush & Saakshi — Wedding Invitation

An animated wedding invitation website for **Aayush & Saakshi**, 26–30 November 2026.

Groom from **Assam**, bride from **Banaras**, with a South Indian touch:

- Banana leaves fan open as you scroll to reveal the invitation
- Assam scene (Kamakhya temple, tea gardens, one-horned rhino, japi, gamosa borders)
- Banaras scene (ghats, Kashi Vishwanath, Ganga aarti, Banarasi brocade)
- Kolam, gopuram and mango-leaf thoranam
- Event cards wrapped in banana-leaf parcels that open on scroll
- Live countdown to the wedding
- Closing "thank you" in Hindi, Assamese, Tamil and English

## Run it

It is a single file. Open `index.html` in a browser, or serve the folder:

```
python -m http.server 8000
```

Built with HTML, CSS and [GSAP](https://gsap.com/) + ScrollTrigger (loaded from a CDN). An internet connection is needed for the fonts and GSAP.
